# Runbooks

This folder holds operational runbooks for this solution: step-by-step
guidance for diagnosing and mitigating operational conditions, written for
whoever is on call.

## Ownership

Runbooks are owned and maintained by this repository, alongside the code and
architecture they operate against. Keep them current as the system changes;
a stale runbook is worse than none, because it is trusted.

## Starter content

- [`templates/runbook.template.md`](templates/runbook.template.md) — copy
  this to create a new runbook (for example `high-latency.md`,
  `failover.md`, `data-backfill.md`).
