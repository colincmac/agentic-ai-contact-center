# Architecture Decision Records (ADR)

This folder holds Architecture Decision Records for this solution. Each ADR
is a stable, dated record of a consequential decision, its alternatives, and
its consequences. ADRs are not a changelog and are not required for every
code change — see [`CONTRIBUTING.md`](../../CONTRIBUTING.md) for when an ADR
is warranted.

## Ownership

ADRs are owned and maintained by this repository. Once accepted, an ADR's
history is not rewritten; supersede it with a new ADR instead (see the
template's **Status** field).

## Starter content

- [`templates/adr.template.md`](templates/adr.template.md) — copy this to
  create `NNNN-short-decision-slug.md`, using the next sequential number.

## Numbering convention

Use a zero-padded, sequential, four-digit ID: `0001-`, `0002-`, and so on.
IDs are stable once assigned and are never reused, even if an ADR is later
superseded or rejected.
